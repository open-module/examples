# Project scope

This repository is a standalone examples project. Keep its examples, hardware references, documentation, issue scope, and release history self-contained.

- Do not describe files here as owned by, synchronized from, or canonical for a peer project.
- Do not add backlinks or migration notes that couple this repository to a peer project.
- External vendor documentation and official sample links are allowed when they are direct technical sources.
- Keep each example's protocol, hardware, safety boundary, tests, and physical-validation evidence local to that example.
