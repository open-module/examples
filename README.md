# Open Module Examples

This repository is dedicated to self-contained example projects for open modules, hardware experiments, and reference integrations.

Each example lives in its own top-level directory and documents its dependencies, build steps, safety boundaries, and validation scope.

## Examples

- [`esp32-cybergear-can/`](esp32-cybergear-can/) — ESP32-S3, SN65HVD230, and CyberGear physical 1 Mbit/s CAN experiment.
- [`esp32-RobStride02-can/`](esp32-RobStride02-can/) — Fail-closed ESP32-S3 and RobStride RS02 1 Mbit/s CAN communication example.

## Hardware references

- [`hardware/SN65HVD230-CAN-Board/`](hardware/SN65HVD230-CAN-Board/) — SN65HVD230 transceiver-board schematic, TI datasheet, pinout, termination, and operating limits.
